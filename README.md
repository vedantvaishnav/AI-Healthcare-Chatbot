# AI Healthcare Chatbot

AI-powered healthcare web application with chatbot, BMI analysis, calorie tracking, water intake tracking, diet planner, and dashboard analytics.

## Features

- AI Chatbot
- BMI Calculator
- Calories Tracker
- Water Intake Recommendation
- Diet Planner
- Exercise & Sleep Tracking
- JWT Authentication
- User-specific Dashboard
- Secure Backend APIs

## Tech Stack

### Frontend
- React
- Tailwind CSS
- Vite

### Backend
- Flask
- SQLAlchemy
- JWT Authentication

### Database
- SQLite

### AI Integration
- Groq API

---

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

---

## Environment Variables

Create `.env` file:

```env
GROQ_API_KEY=your_key
JWT_SECRET_KEY=your_secret
```
